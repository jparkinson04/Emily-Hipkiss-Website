# Emily Hipkiss Counselling & Therapy

Astro site by Seam Digital Studio. Start with `CLAUDE.md`, then `docs/BUILD-PLAN.md`.

```
npm install
cp .env.example .env   # add the Web3Forms key
npm run dev
```

Adding a blog post: copy `src/content/blog/_example.md`, rename to a slug, fill in frontmatter, `draft: false`, commit. Vercel redeploys on push.
